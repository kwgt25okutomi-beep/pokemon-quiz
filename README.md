# ポケモンダレダ！？ (Poké-Name Shuffle Quiz)

ポケモンの名前を使った伏字・シャッフル推理クイズWebアプリケーションです。

## 特徴
- 🎯 **ノーマルモード**: 名前の並び順そのままに伏字パネルを配置。タップすると3秒間だけ文字が見える！
- 🌀 **ハードモード**: 名前の文字がバラバラにシャッフルされた高難度アナグラム！
- 🔴 **ポケモン図鑑UI**: ポケモン図鑑（Pokédex）とモンスターボールをモチーフにした洗練されたデザイン。
- 📱 **レスポンシブ対応**: スマートフォン（縦持ち）でもPCでも快適にプレイ可能。
- 🔊 **シンセ効果音**: Web Audio API による心地よいピコピコ効果音（外部ファイル不要・即時再生）。
- 🎨 **公式アートワーク表示**: 正解するとポケモンの公式イラストと図鑑No.が表示されます。
- 📚 **世代別絞り込み**: 第1世代（カントー）から第9世代（パルデア）まで世代を選択して遊べます。

## 起動方法
```bash
node server.js
```
ブラウザで `http://localhost:8080/` を開いてください。
